API documentation

Every published website shows Webora ads. There is no limit on the number of websites you can publish.
POST /api/publish
# Create or update a website
curl -X POST https://webora-lovat.vercel.app/api/publish \
  -H "Content-Type: application/json" \
  -H "X-Api-Key: YOUR_API_KEY" \
  -d '{
    "path": "my-site",
    "title": "My Site",
    "description": "Made via the Webora API",
    "html": "<h1>Hello from the API</h1>",
    "css": "h1{color:#7a35c9}",
    "js": "",
    "mode": "create"
  }'

# Response
{ "ok": true, "path": "my-site", "url": "https://webora-lovat.vercel.app/my-site" }

path can also be my-site.webora.app, .webora.online or .webora.site. mode is create or update.

POST /api/image
# Upload an image (PNG, JPG, GIF, WEBP, max 3 MB each, no daily limit)
curl -X POST https://webora-lovat.vercel.app/api/image \
  -H "Content-Type: application/json" \
  -H "X-Api-Key: YOUR_API_KEY" \
  -d '{ "name": "logo", "data": "BASE64_IMAGE_DATA" }'

# Response
{ "ok": true, "id": "a1b2c3d4e5f60718", "url": "https://webora-lovat.vercel.app/img/a1b2c3d4e5f60718.png" }

Use the returned url directly in <img src> or CSS. It is served from Webora, never from a third-party host. Prefer a UI? Use the Images page to upload, copy links and delete without writing any code.

GET /api/image?action=list
# Your upload history
curl https://webora-lovat.vercel.app/api/image?action=list \
  -H "X-Api-Key: YOUR_API_KEY"

# Response
{ "ok": true, "images": [ { "id": "a1b2c3d4e5f60718", "name": "logo", "ext": "png", "size": 20480, "url": "https://webora-lovat.vercel.app/img/a1b2c3d4e5f60718.png", "createdAt": 1732000000000, "deleted": false } ] }
DELETE /api/image
curl -X DELETE https://webora-lovat.vercel.app/api/image \
  -H "Content-Type: application/json" \
  -H "X-Api-Key: YOUR_API_KEY" \
  -d '{ "id": "a1b2c3d4e5f60718" }'

The link keeps working, but opening it now shows "File was deleted" instead of the image.
