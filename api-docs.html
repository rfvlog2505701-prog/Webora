API documentation

Websites published through the API carry Webora ads on the live page. Dashboard sites do not. Requests are unlimited, but you are still capped at 3 live websites per account.
POST /api/publish
# Create or update a website
curl -X POST https://webora-lovat.vercel.app/api/publish \
  -H "Content-Type: application/json" \
  -H "X-Api-Key: YOUR_API_KEY" \
  -d '{
    "path": "my-site",
    "title": "My Site",
    "description": "Made via the Webora API",
    "html": "<h1>Hello from the API</h1>",
    "css": "h1{color:#7a35c9}",
    "js": "",
    "mode": "create"
  }'

# Response
{ "ok": true, "path": "my-site", "url": "https://webora-lovat.vercel.app/my-site" }

path can also be my-site.webora.app, .webora.online or .webora.site. mode is create or update.

DELETE /api/publish
curl -X DELETE https://webora-lovat.vercel.app/api/publish \
  -H "Content-Type: application/json" \
  -H "X-Api-Key: YOUR_API_KEY" \
  -d '{ "path": "my-site" }'
